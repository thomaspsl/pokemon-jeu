  ## 📚 Description

  Pékamon is a retro-style 2D video game inspired by the nostalgic Pokémon universe from the Nintendo DS era, where every second counts! The player has 60 seconds to catch as many creatures as possible while managing a limited number of Pokéballs. Each Pékamon has its own rarity level affecting its capture difficulty, and special balls offer higher chances of success. Developed with Unity, the project blends nostalgia, speed, and strategy in a colorful, charming pixel-art world.

  ## 🚀 How To Use

  To clone and run this application, you'll need [Git](https://git-scm.com) (which comes with [npm](https://www.npmjs.com)) installed on your computer. From your command line:

  ```bash
  # Clone this repository
  $ git clone https://github.com/thomaspsl/pekamon-jeu

  # Go into the repository
  $ cd pekamon-jeu

  # Then open it with Unity Hub
  ```
